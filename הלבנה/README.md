# הלבנה – העברה למחשב הסגור

בתיקייה הזו נמצאת תמיד הגרסה העדכנית של האפליקציה, כשלושה קבצי Word שעוברים את ההלבנה:

1. `1 - israeli-road-learner (html).docx`: האפליקציה
2. `2 - bm-1 (js).docx`: המפה, חלק 1
3. `3 - bm-2 (js).docx`: המפה, חלק 2

## התקנה במחשב הסגור
פותחים כל קובץ ב-Word ← שמירה בשם ← סוג: **Plain Text** ← בחלון הקידוד: **Other encoding → Unicode (UTF-8)**.
שמות הקבצים, כולל המירכאות:

- `"israeli-road-learner.html"`
- `"bm-1.js"`
- `"bm-2.js"`

שלושת הקבצים צריכים להיות באותה תיקייה. פותחים את `israeli-road-learner.html` בדפדפן.
כשהמפה לא השתנתה, מספיק להחליף רק את קובץ 1.

הקבצים נוצרים אוטומטית ב-`tools/offline/build_offline.py`.
