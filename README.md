# סימולציה אינטראקטיבית ללמידת כבישי ישראל
**Israeli Road Learner** – לומדים את כל הכבישים הממוספרים בישראל על מפה אמיתית.

▶️ **לשחק:** https://luckydan1mc-arch.github.io/israeli-road-learner/

## מה יש בפנים
- **868 כבישים ממוספרים** – חד־ספרתיים, דו־ספרתיים, תלת־ספרתיים וארבע ספרות, כולל יהודה ושומרון והגולן, עם התוואי המלא שלהם.
- **סינון לפי מספר ספרות ולפי 20 אזורים ו־54 מועצות אזוריות** – כדי ללמוד בחלקים ("הפרד ומשול").
- **מצב לימוד** – כרטיס לכל כביש, המפה מתמקדת בו, ותצוגת גוגל מפות באותו מסך.
- **חידון** – סבב מלא על כל הכבישים שבסינון, בשלושה סוגים: בחירה מ־4 אפשרויות, לחיצה על הכביש הנכון במפה, או הקלדת מספר הכביש. בסוף כל סבב – סבב חוזר על הטעויות.
- **צמתים ומחלפים** – כ־725 צמתים ומחלפים עם הכבישים שנפגשים בכל אחד, באותו סינון של ספרות ואזורים. בחידון: לזהות צומת מסומן, ללחוץ על צומת במפה, באיזה צומת נפגשים שני כבישים, או להקליד את הכבישים שנפגשים בצומת.
- ההתקדמות נשמרת בדפדפן.

## איך זה בנוי
הכול בקובץ אחד, `index.html`, עם הנתונים בתוכו. מפת הרקע היא OpenFreeMap (לוויין: Esri), והמפה מצוירת עם Leaflet ו־MapLibre.

הנתונים נבנים מתוך מפת ישראל של OpenStreetMap:
```bash
pip install osmium shapely numpy
# הורדה: https://download.geofabrik.de/asia/israel-and-palestine.html
tools/build.sh israel-and-palestine-latest.osm.pbf
```
- `tools/extract_roads.py` – שולף כל דרך עם מספר כביש, ממזג למסלולים ומסנן כבישים מחוץ לישראל/יו"ש/הגולן.
- `tools/enrich.py` – קצוות הכביש, יישובים לאורכו.
- `tools/junctions.py` – צמתים ומחלפים בעלי שם (צומת…/מחלף…) והכבישים הממוספרים שעוברים בכל אחד.
- `tools/regions.py` – חלוקה לאזורים לפי גבולות המועצות והרשויות, חיתוך על הקו הירוק ועל קו החוף, ושיוך כל כביש לאזורים שהוא עובר בהם.

## הערות
- הקיבוץ של המועצות ל־20 אזורים הוא חלוקה לימודית, לא רשמית.
- שמות קצוות הכבישים נקבעים אוטומטית לפי היישוב הקרוב ולכן ייתכנו אי־דיוקים. מוזמנים לפתוח Issue.
